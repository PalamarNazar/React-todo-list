# Ветка миграции на TypeScript

Эта ветка предназначена для постепенного перевода проекта с **JavaScript** на **TypeScript**.  

### Что было изменено:
- Все `.js` файлы переименованы в `.ts` или `.tsx`.
- Добавлены типы для:
  - Пропсов компонентов
  - Контекстов
  - Редьюсеров и состояния
  - API методов
  - Кастомных хуков
- Обновлены компоненты React с использованием типов и интерфейсов TypeScript.
- Исправлены ошибки типов, добавлены явные типизации для событий, ref и состояния.
- Обновлены утилиты и общие типы.

### P.S.
- Эта ветка является учебным проектом для практики TypeScript.
- Основная функциональность осталась прежней — фокус на безопасности типов.
